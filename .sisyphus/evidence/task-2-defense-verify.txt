TASK 2: Defense-in-Depth for writeAccountTokens()
==================================================

OBJECTIVE:
Add filtering of undefined values before merge in writeAccountTokens() to prevent
accidental overwriting of existing token data via spread operator.

IMPLEMENTATION:
File: src/lib/state.ts (lines 97-99)

Before:
  const existing = readAccountTokens(label);
  const merged = existing ? { ...existing, ...tokens } : tokens;

After:
  const existing = readAccountTokens(label);
  const cleanTokens = Object.fromEntries(Object.entries(tokens).filter(([_, v]) => v !== undefined));
  const merged = existing ? { ...existing, ...cleanTokens } : cleanTokens;
